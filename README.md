# 🌍 AIwanna — Smart Travel Recommendation App

**AIwanna** is a simple yet powerful travel recommendation app that helps users **discover new destinations and experiences**.  
By allowing users to input vacation details — such as **images, descriptions, and locations** — the app leverages **Gemini AI** to generate **personalized travel suggestions**.

---

## 🚀 Tech Stack

**Framework:** [Next.js](https://nextjs.org/)  
**Language:** [TypeScript](https://www.typescriptlang.org/)  
**Styling:** [Tailwind CSS](https://tailwindcss.com/)  
**AI Engine:** [Gemini AI (Google Generative AI)](https://ai.google/)  
**Deployment:** [Vercel](https://aiwanna.vercel.app/)

---

## ✨ Features

- 🧭 Input custom vacation details (image, location, description)  
- 🧠 Get **AI-powered** travel recommendations via Gemini AI  
- 🌄 View curated destination suggestions and experiences  
- 📱 Fully responsive UI with Tailwind CSS  
- ⚡ Built with Next.js + TypeScript for fast and type-safe development  
- 💬 Smooth UX with instant result rendering
